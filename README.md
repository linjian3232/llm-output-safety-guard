# 中文模型回复安全检测：微调实战

这个仓库用于学习一条可迁移的模型工程流程：**从本地模型与数据文件出发，制作训练集、训练分类器、进行 LoRA 微调、评测，并提供 API 推理**。第一轮处理中文模型*回复*的内容安全分类；不是输入提示词检测，也不是直接训练生成式大模型。

学习方式是每次只推进一个阶段：先说明实际问题和必要概念，再提供代码与命令，由学习者亲自运行资源准备、训练和推理，最后根据真实输出检查结果。代码中的关键处理会写中文注释。完整路线见[学习计划](docs/learning-plan.md)。

## 当前进度

## 仓库与本地资源的边界

Git 保存代码、文档、经过审查的配置，以及后续的 `pyproject.toml` 和 `uv.lock`。`artifacts/` 下的模型与训练产物、`data/` 下的原始及加工数据、`reports/` 下可能包含敏感统计的报告不提交。换一台电脑时，从 Git 同步流程，再按记录的来源与 SHA256 准备相同资源。

训练和推理代码只从**本地路径**加载模型与数据；运行时不要求连接 Hugging Face。Python 依赖通过 uv 和可用的包源安装；这与模型文件的来源是两件不同的事。

此前 Iris 项目中调节逻辑回归的 `C`、`solver` 属于传统机器学习的超参数选择；后续 LoRA 则是在预训练神经网络中训练少量新增参数。我们会用基线和同一套指标来比较它们，但不会把两种操作混为一谈。
