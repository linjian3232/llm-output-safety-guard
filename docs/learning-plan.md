# 学习计划：中文回复安全检测

## 目标与约束

通过一个完整项目，学会准备模型文件、处理数据、训练冻结编码器基线、进行 LoRA 微调、评测和 API 推理。首个模型使用 `hfl/chinese-roberta-wwm-ext`；主流程跑通后，换用 `google-bert/bert-base-chinese` 做短运行，验证流程可迁移，而不将短运行指标与完整训练比较。

以 Java 开发经验为起点，Python、机器学习与深度学习基础在用到时讲清楚；测试是工程保障，不单独成为教学主线。每阶段只交付一个可运行、可观察的结果。讲解顺序是：**为什么做 → 命令或代码的作用 → 预期输出 → 实际运行与排障**。我编写必要代码及详细中文注释；学习者亲自运行资源准备、训练和推理命令。每阶段结束时留下可复现的操作说明，并提交、推送该阶段代码。模型和数据的实际获取、训练与推理运行由学习者完成。

环境约束：Windows、PowerShell、Python 3.12、uv；通过可用的内网包源安装 Python 依赖。模型、Tokenizer 和数据通过文件转移，训练及推理只使用本地路径。第一轮在 CPU 上完成中文**模型回复**分类。生成式大模型、QLoRA、Docker 和输入端检测留待主流程跑通后讨论。

## 阶段路线

| 阶段 | 实操目标与验收 | 结合实操掌握的通用知识 |
| --- | --- | --- |
| 0. 固定计划、取得模型 | 将计划提交 Git；从固定版本取得模型配置、PyTorch 权重和 Tokenizer 文件，记录版本与 SHA256 | 识别模型仓库与文件；区分预训练编码器和安全分类器；为什么固定版本、校验传输文件 |
| 1. uv 环境与本地加载 | 建立独立项目环境；完全从本地目录完成一次中文文本前向推理 | `pyproject.toml`、`uv.lock`、`.venv` 的职责；`uv add`、`uv sync`、`uv run`；当前代码中的导入、函数、字典、路径和张量 |
| 2. 获取并审计原始数据 | 学习者取得 XGuard JSONL；脚本只读本地文件，生成不含原文的字段、标签、语言和长度报告 | 特征文本与标签；空值、类别不平衡、语言混杂；逐行读取 JSONL |
| 3. 制作训练集 | 保留 `general + stage=r` 的非空中文回复，处理重复和冲突；每类最多 400 条，`seed=42` 分层切分 80/10/10 | train、validation、test 的职责；数据泄漏、随机种子和标签映射；检查集合无交叉 |
| 4. 冻结编码器基线 | 先少量训练步数验证流程，再训练只更新分类头的基线；保存 checkpoint 和验证指标 | Tokenizer、batch、epoch、logits、loss、反向传播、冻结参数；训练 loss 与验证指标的区别 |
| 5. PEFT / LoRA | 同一数据与评测方式，在 attention 的 `query`、`value` 上训练 LoRA，分类头保持可训练；保存 adapter | 基础权重、可训练参数、adapter；传统模型调参与深度模型微调的区别 |
| 6. 评测与拦截决策 | 比较 Macro-F1、逐类召回率和混淆矩阵；验证集选阈值，测试集只做最终验收 | Accuracy 的局限；危险漏判与安全误拦；从 `unsafe_score = 1 - P(sec)` 到业务决策 |
| 7. 更换同类模型 | 换用本地中文 BERT 文件，保持数据接口、训练入口和指标定义，完成加载与少量训练步数 | 新模型的配置与文件如何核查；可复用的流程与必须调整的配置 |
| 8. 本地 API | 本地加载基础模型、adapter、标签和阈值；用 Uvicorn 调用 `/health` 与 `/moderate` | 离线训练与在线推理；版本化配置和服务交付 |

## 默认实验约定

- 主模型固定版本和下载文件见[阶段 0 说明](stage-0-model-files.md)。数据源为 XGuard 的回复级样本；数据具体版本会在阶段 2 固定。
- 第一轮训练默认最大长度 128、batch size 8、3 个 epoch；以 CPU 可运行性为前提，真实耗时和内存占用在训练阶段观察。
- LoRA 初始配置：`r=8`、`alpha=16`、`dropout=0.05`。具体模块名和可训练参数必须在加载本地模型后核验，不能仅根据仓库名称推断。
- 阈值在验证集上选择：安全回复误拦率不超过 10%，在满足该限制的候选阈值中尽量提高不安全回复召回率。测试集不得用于反复选择阈值。
- 每次实验记录数据版本、模型版本、配置、指标与产物。代码提交 Git；模型权重、原始数据和含正文的样本不提交。

完成标准：面对另一份本地中文 BERT 类模型文件和相同任务格式的数据，学习者能识别所需文件、配置 uv 环境、运行数据处理与微调、读懂主要指标，并加载产物推理。不同架构的生成式模型需要另建训练流程。
